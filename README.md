# WordSearchWebApp

A separate example of the Word Search Puzzle Generator project. The app shows a list of different puzzles to choose from, and each puzzle page hosts a randomised puzzle based on the selected subject. Demonstrates how parts of a (simplified) full stack web app can work, to code club students.

## Requirements

    The Flask package must be installed.

## Running the App

To run the app, use this command from the same directory as the project root:

```
    flask --app app --debug run
```
